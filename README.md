# Mythikos Admin para Mac

O painel da agência como aplicativo de Mac: pedidos, clientes, milhas, Journeys, grupos e vitrines.

## Instalar

1. Abra a página de [versões](https://github.com/Mythikos-Journeys/mythikos-admin-releases/releases/latest) e baixe o arquivo `Mythikos-Admin-x.y.z.zip`
2. Dê dois cliques no arquivo baixado. Aparece o `Mythikos Admin`
3. Arraste o `Mythikos Admin` para a pasta **Aplicativos**
4. Abra pelo Launchpad ou pelo Spotlight (⌘ + espaço, digite "Mythikos")
5. Entre com o e-mail e a senha do admin

## Requisitos

- Mac com macOS 26 ou mais novo
- Processador Apple (M1 ou mais novo)

## Atualizações

O aplicativo confere sozinho se existe versão nova. Quando existir, aparece uma faixa no topo com o botão **Atualizar**. Um clique baixa, troca e reabre.

## Se o Mac não deixar abrir

Abra **Ajustes do Sistema > Privacidade e Segurança**, role até o fim e clique em **Abrir Mesmo Assim**.
